### 👨‍💻 Về Bản Thân (About Me)

- 🔭 **Hiện tại:** Tập trung phát triển giao diện người dùng hiện đại, tối ưu **Core Web Vitals** và kiến trúc **CSS Design Tokens**.
- 🌱 **Đang nghiên cứu & nâng cao:** Kiến trúc Component hiện đại, CSS Grid nâng cao, Web Accessibility (WCAG 2.1) và tối ưu hóa SEO On-page.
- 💡 **Thế mạnh:** Biến ý tưởng từ Figma thành mã nguồn sạch (Clean Code), chuẩn Semantic HTML5, Responsive mượt mà trên mọi thiết bị.
- 🎯 **Mục tiêu:** Trở thành một Senior Front-end Engineer kiến tạo các sản phẩm số mang lại giá trị thực cho hàng triệu người dùng.
- ⚡ **Sở thích:** Khám phá công nghệ web mới, tối ưu hiệu năng trang web và đóng góp vào cộng đồng mã nguồn mở.
